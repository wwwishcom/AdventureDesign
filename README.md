# 🚌 Bus-ing

> 교통약자의 더 편리한 이동을 위한 스마트 버스 이용 지원 서비스

Bus-ing은 버스 이용 과정에서 발생하는 불편함을 해결하고,  
교통약자의 이동 접근성을 높이기 위해 기획된 서비스입니다.

사용자가 보다 쉽고 안전하게 대중교통을 이용할 수 있도록  
실시간 정보 제공, 사용자 중심 기능, 접근성 개선 요소를 제공합니다.

---

## Problem

대중교통은 많은 사람들이 이용하지만,  
교통약자에게는 여전히 높은 진입장벽이 존재합니다.

대표적인 문제점:

- 버스 도착 정보 확인의 어려움
- 복잡한 환승 및 노선 파악
- 시각·청각 정보 접근성 부족
- 이동 과정 중 발생하는 불안감과 정보 부족

Bus-ing은 이러한 문제를 해결하고자 시작되었습니다.

---

## Features

### 실시간 버스 정보 제공
- 버스 도착 예정 시간 확인
- 노선 및 정류장 정보 조회
- 현재 운행 정보 제공

### 교통약자 친화 기능
- 접근성 중심 UI/UX 설계
- 직관적인 정보 구조
- 사용 편의성을 고려한 화면 구성

### 사용자 맞춤 이동 지원
- 목적지 기반 이동 경로 탐색
- 환승 정보 안내
- 효율적인 이동 동선 제공
